# Модель гравитационной задачи N тел

Программа моделирует эволюцию системы из N материальных точек, взаимодействующих по закону всемирного тяготения Ньютона. Моделирование разделено на два параллельных потока для визуального сравнения:
- Метод PP (Particle-particle) (по алгоритму Барнса-Хата): расчёт прямых силовых взаимодействий между частицами. Близкие тела считаются индивидуально, далёкие группы тел группируются в эквивалентные им тела; 
- Метод PM (Particle-Mesh): Пространство разбивается на регулярную сетку. Массы частиц интерполируются на узлы сетки (распределение плотности), затем вычисляется гравитационный потенциал в узлах, берутся градиенты потенциалов для получения сил, и силы интерполируются обратно на частицы.

## Особенности и параметры модели

- Моделирование `N` частиц и `1` центрального тела на поле размером `X` на `Y` с задаваемым шагом по времени `dt` и числом шагов `num_steps`;
- Интегрирование методом с перешагиванием (leapfrog);
- Гравитационная постоянная `G` принята равной `1` условной единице (у.е.) некоторой абстрактной системы измерений;
- Размерности параметров (масса, расстояние, скорость и пр.) в у.е.;
- Генерация поля:
  - размеры поля `X` на `Y` задаются вручную или берутся из базовых значений;
  - число частиц `N` задаётся вручную или берётся из базового значения;
  - массы частиц случайно генерируются из задаваемого или базового диапазона `[m_min, m_max]` у.е. массы;
  - масса центрального тела задаётся вручную или берётся из базового значения;
  - положение центрального тела фиксировано;
  - положения частиц генерируется случайно внутри области;
  - частицам придаётся небольшая начальная тангенциальная скорость из базового диапазона `[0.9, 1.1]` у.е. скорости.

## Ограничения

- Не рассматриваются столкновения, слияния, поглощения частиц;
- Случайные начальные условия;
- Параметр `θ` для расчёта по алгоритму Барнса-Хата принят `0.5`.

# **Программная реализация**

  Программа имеет интерфейс в консоли IDE. При запуске программы в консоль IDE выводится меню вида:

            <Меню>
    1. Текущие параметры
    2. Ввод параметров
    3. Расчёт
    4. Выход
    <Ввод>: 
    
## Пункты меню
  - Пункт 1: выводит текущие заданные параметры модели;
  - Пункт 2: позволяет поочерёдно ввести собственные параметры для расчёта;
  - Пункт 3: запускает расчёт с заданными параметрами или параметрами по умолчанию;
  - Пункт 4: завершает работу программы.

 ## Задаваемые в п.2 параметры:
  - `N` - количество тел, int, не менее 1;
  - `dt` - шаг по времени, float, не менее `1e-6`;
  - `num_steps` - количество шагов/кадров, int, не менее 1;
  - `cm` - масса центрального тела, float, не менее 0 (0 эквивалентно отсутствию центрального тела);
  - `m_min` - нижний порог диапазона масс частиц, float, не менее 0.1;
  - `m_max` - верхний порог диапазона масс частиц, float, не менее `m_min`;
  - `x_min` - расстояние до левой границы поля, float;
  - `x_max` - расстояние до правой границы поля, float, не менее `x_min`;
  - `y_min` - расстояние до нижней границы поля, float;
  - `y_max` - расстояние до верхней границы поля, float, не менее `y_min`;

  В результате расчёта по п.3, выводом являются графики с первого и последнего шагов, текстовый вывод в консоль равнодействующей силы для центрального тела (векторов и по модулю) для каждого метода, а также анимация "animation.gif", которая сохраняется в папке с программой.
